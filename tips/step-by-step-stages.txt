### Step-by-Step Stages to Vibe-Code Your Portfolio

1. **Content, IA & Asset Prep**
* Curate project case studies, links, and text copy.
* Export all images/videos to optimized AVIF/WebP/WebM formats.


2. **Project Scaffolding & Build System**
* Set up a modern frontend workspace (e.g., Vite + React or Next.js static export).
* Configure Tailwind CSS and path aliases.


3. **Core Static UI & Layout Architecture**
* Build responsive components (Hero, Projects grid, About, Tech Stack, Contact).
* Implement semantic HTML tags (`<header>`, `<main>`, `<section>`, `<footer>`) and ARIA labels.


4. **Motion & Interaction Layer (Motion.dev + React Bits)**
* Integrate `<LazyMotion>` for lightweight route/card transitions.
* Add a single React Bits background canvas/shader strictly inside the Hero section.
* Attach `IntersectionObserver` controllers to halt background loops off-screen.


5. **Serverless Functions & Bot Protection**
* Write an edge function (e.g., Cloudflare Pages Functions) for the contact form.
* Embed Cloudflare Turnstile bot verification and input validation logic.


6. **Security Headers & Cloudflare Configuration**
* Create a `public/_headers` file containing CSP, HSTS, and frame-guard policies.
* Configure `.gitignore` and audit code for exposed secrets.


7. **SEO, OpenGraph & Accessibility Audit**
* Add meta tags, `og:image`, `robots.txt`, and `sitemap.xml`.
* Add `prefers-reduced-motion` fallbacks to disable intensive animations when requested by the OS.


8. **CI/CD & Edge Deployment**
* Push repository to GitHub and connect to Cloudflare Pages (should be deployed to "simon-escano.pages.dev").
* Set production build command (`npm run build`) and output directory (`dist`/`out`).


9. **Performance Auditing & Production Launch**
* Run Google Lighthouse to verify 95+ scores across Performance, Accessibility, and SEO.
* Enable Cloudflare Web Analytics for zero-JS privacy-friendly metrics.
